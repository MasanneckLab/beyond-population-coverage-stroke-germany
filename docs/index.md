# Urban-rural disparities in access to acute stroke care in Germany: a nationwide geospatial analysis

Corrected cross-sectional 2024 analysis accompanying the manuscript prepared for
the Journal of Neurology. Code is released under MIT. No hospital-level datasets,
routing caches, manuscript files or Supplement PDF are published here.

See the [repository README](https://github.com/MasanneckLab/beyond-population-coverage-stroke-germany#readme)
and [reproduction instructions](reproduction.md). This is a static documentation
page, not an interactive hospital map.
